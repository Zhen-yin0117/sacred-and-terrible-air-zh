## 如何保存

1. 在本页点右上角 **Code → Download ZIP**，解压后即可得到 PDF 和 EPUB。
2. 也可以直接点开对应文件，再点 **Download raw file** 单独下载。
3. 手机保存：iOS 可存入“文件”后用 Apple Books 打开 EPUB；Android 可用 ReadEra、KOReader 等阅读器。PDF 用任意 PDF 阅读器即可。
4. 电脑保存：EPUB 可用 Apple Books、Calibre 或 Thorium 打开；PDF 用任意 PDF 阅读器。
5. 建议两种格式都保留：PDF 版式固定，EPUB 方便随时调字号阅读。
